RIFT

The brief manual · covers v0.12 PATCHING

RIFT is a second firmware for the Elektron Digitone II (OS 1.11), separate from the DN2 mk2 mod. It drops the Machinedrum and Monomachine machines and puts new engines in their place, and keeps the Digitakt II sample machines, FLEX, the +Drive library, recording, Direct Jump and parameter slides. Unofficial: not made or supported by Elektron.

Install & recovery

  • Back up first, every time: the +Drive and your projects with Elektron Transfer.
  • Build the file in the DN2 Mod Patcher (its RIFT section) from your own stock files; it only lets you save a file that is byte for byte the cleared build. Flash it over USB like any OS update.
  • Keep the stock OS 1.11 file and a DIN MIDI cable for recovery (the patcher's Flash section). The start-up code and the updater are Elektron's own, untouched.
  • From the DN2 mk2 mod: Perc and Monomachine tracks open as FM Tone. Keep RIFT projects apart from the mod's and stock's; RIFT's machines do not sound on either.

The screens (LINE)

  • MACHINE SEL ([FUNC] + [SYN]): RIFT's machines come after Swarmer, then the sample machines.
  • Each page shows eight controls in two rows of four, laid out like the knobs. Each has a small icon that moves as you turn it; word choices sit in boxes.
  • Values show while you turn a knob, while you hold SYN, or while you hold a trig: the trig's p-locked controls are highlighted, with their locked values.
  • [FUNC] + turn is a shortcut on some controls (FASCIA: TUNE by octaves; GEOM and SHIFT snap to 0). TRK + CLEAR returns a machine to its own start values.

LIGATURE

A patchable synth: twelve blocks wired into a voice, as WEFT. Page 1 shows the wiring PATCH plays: twelve tiles in three rows (1-9, A, B, C) with their cables (a cord back to an earlier block dotted), and the page's controls below. YES opens EDIT: A picks the block, B its type, C and D input A and its amount, E and F input B and its amount, G B MOVES (B moves setting 2), H the output block; the arrows move between tiles; FUNC + NO empties a block; YES shows the BLOCK view (its inputs, its settings, where it goes); NO leaves. Every change plays at once and is kept in the project (128 wirings; PATCH picks one, p-lockable). Pages 2-4: each block's two settings, named for its type.

Sample machines & FLEX

Oneshot, Werp, Stretch, Repitch, Grid, Slice and Flex, from the Digitakt II, work as in the DN2 mk2 mod: samples from the +Drive, the recorder, slices, Direct Jump and slides. FLEX records into buffers B1–B8, which every sample machine can play from SAMP. The DN2 mk2 mod's own manual pages describe them in full.

Versions

Each build contains everything before it; flash only the newest.

v0.12 · PATCHING
  • LIGATURE: patch it yourself. Page 1 shows the wiring as tiles and cables; YES opens EDIT (A block, B type, C/D input A and amount, E/F input B and amount, G B MOVES, H output; arrows move, FUNC + NO empties a block, YES the BLOCK view, NO leaves).
  • Each project keeps 128 wirings; PATCH (1..128) picks one, p-lockable. They start as the old patches, so earlier LIGATURE tracks sound the same.
  • Pages 2-4: each knob named for its block's setting (1RISE, 3CUT ...).
v0.11 · VOICEKEEP
  • Held notes keep the CPU: on a busy track a melody's or a re-struck note's tail is dropped before a held chord's notes (dreamsaremaps).
v0.10 · DIGIDRUM
  • DIGIDRUM: six Syntakt-style digital drum voices, the TYPE p-lockable per trig.
  • A v0.8 RESONATOR track never re-saved in v0.9 opens as DIGIDRUM, with odd settings.
v0.9 · LINE
  • LINE, the new screen for every RIFT machine: thin lines, one moving icon per control, two rows of four that sit where the knobs are; no side panel.
  • Values show the Syntakt way: while a knob turns, while SYN is held, or while a trig is held (its locked cells highlighted, with their values).
  • LIGATURE is in MACHINE SEL.
  • RESONATOR is removed; a saved RESONATOR track opens as FM Tone.
v0.8 · RESONATOR
  • RESONATOR (removed again in v0.9).
v0.7 · FLEXPOOL
  • FLEX buffers B1–B8 in every sample machine's SAMP; MUTE SRC only while the FLEX track plays; the stock NAME screen for file names; turned knobs show their value.
v0.6 · SILT
  • SILT, RIFT's third machine.
v0.5 · BREATH
  • ORGAN pages 3 (ATTACK) and 4 (BREATH).
v0.4 · ORGAN
  • ORGAN, RIFT's second machine.
v0.3 · FLEX
  • FLEX from the DN2 mk2 mod.
v0.1 · FASCIA
  • FASCIA; the Machinedrum and Monomachine engines removed (their tracks open as FM Tone).
