SYNTH MACHINE

WHAT HITS THE BODY

Choose a second exciter for hybrid attacks.

Soft mallet → hard tip; bow pressure; breath brightness.

DDUST

Extra grit, rosin noise or micro-impacts.

Metallic FM edge; more = harsher.

SYN2 / RESONATORS

WHAT RINGS
ABODA

Optional second body; OFF disables it.

Harmonic/woody → inharmonic/metal. [FUNC]+turn: centre.

EMATL

High harmonics die fast → ring longer.

FPOS

Strike location; changes overtone mix.

GCOUP

How strongly A excites body B.

HDAMP

LOW = long ring; HIGH = short thud.

Spectral colour changes over the tail.

Vowel-like resonances: a/e/i/o/u.

Ring-modulate the resonators together.

ESIDE

Sideband ratio for the TZFM exciter.

FFOLD

Wavefold for bright buzzy harmonics.

GLPG

Darker and quieter as the note dies.

HCHAR

Output saturation: warmth → grit.

SYN4 / ONSET

SYNTH MACHINE

What each block type does, and what an input can listen to.

SOUND + SHAPE

OSCILLATORS / FILTERS / RESONATORS
PHAS

Ramp oscillator at the note x a ratio; FM on A, sync on B.

WAVE

Waveshaper osc: sine → tri → saw → square.

LP / BP / HP

Resonant 12 dB filter outputs; B moves the cutoff.

SKIN

Drum-skin resonator: strike it for toms.

BAR

Free-bar resonator: marimba / glock.

IMPL

Impulse train or tick: strikes resonators.

FOLD

Sine wavefolder: west-coast overtones.

SAT

Soft saturator with even-harmonic bias.

CRES

A fold at zero: a hard, buzzy edge.

CRSH

Bitcrusher and sample-rate reducer.

CONTROL + LOGIC

ENVELOPES / LFOS / CLOCKS
SLOP

Attack/decay envelope from each note.

ENV

Attack/release that holds with the gate.

CYCL

LFO / slow oscillator, triangle to ramp.

LISA

Lissajous LFO: complex slow shapes.

SLEW

Lag / portamento, up and down times.

HOLD

Sample & hold, optional steps and glide.

TICK

Tempo-locked clock with chance.

CDIV

Clock divider / multiplier.

RUNG

Rungler: chaotic looping 8-step pattern.

CHAO

Logistic map: stepped chaos.

DUST

Random clumped impulses: rain, crackle.

MIX + MATH

VCAs / COMPARATORS
ADD

A + B + offset, times gain.

MULT

A x (B + offset): the VCA, ring mod.

VCA

Gain with a linear → audio-taper curve.

MIX

Crossfade A → B.

COMP

Comparator: gates and pulses.

XOR

Logic: high when one of A/B is high.

FLIP

Flip-flop: divides a clock or pitch by 2.

FLEX / LIVE RECORDING

SAMPLING

A direct guide to every recording decision, from source to saved sample.

01CHOOSE FLEX

Place FLEX on a track; BUF selects buffer B1-B8. Any sample machine can also play B1-B8.

02OPEN REC

[FUNC]+[VOICE] opens the FLEX recorder. LEFT / RIGHT: REC TRIGS / REC SETUP / REC BUS.

03SOURCE / SRC

TRK1-16 = a track; IN = input; MAIN = mix; BUS = chosen tracks (pick them on REC BUS with the [TRIG] keys).

04R.LEN

Recorded take length in pattern steps; [FUNC]+turn moves 16 steps.

05TRIG / Q.REC

On REC TRIGS: [TRIG] = one-shot, [FUNC]+[TRIG] = every pass, [PAGE] = next 16 steps. Or [YES] while playing: records at the next Q.REC boundary; [NO] cancels.

06PLAY / SAVE

FLEX plays its buffer; [FUNC]+[YES] saves the take to the next empty slot and the +Drive.

RECORDER OPTIONS

MUTE SRCKeeps the source out of the mix while FLEX plays it (held 0.2 s after the note).
GAINTake level: 0 = the source's own level; turn down if a bus or MAIN clips.
ONE-SHOT TRIG[YES] [YES] re-arms spent one-shots.
CLEAR BUF[FUNC]+[NO] on REC SETUP, then [YES]: erases the take.
Q.RECQuantized trigless recording: 1-64 steps or the pattern length.
FIRST SOUND / CPU SAVER

Record a heavy track into B1 → FLEX note trig on step 1 plays it → MUTE SRC ON
